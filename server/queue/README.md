# Глобальный фид кластера
* Пропускает через себя запросы к базам всех отделов всех абонентов, которые обслуживает экземпляр
* Выполняет (при необходимости), пересчёт документов
* Рассчитывает строку route репликаций
* В собственной базе PG, регистрирует изменения
* Имитирует ответ `_changes` с ограниченным фильтром
